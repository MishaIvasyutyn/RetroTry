# Lincoln Karaoke — Retro Arcade Edition

A retro pixel-arcade styled experiment for the Lincoln Karaoke site —
inspired by classic 1991 arcade title screens. Same venue, same info,
player-one aesthetic.

- Pure static HTML/CSS/JS, no build step.
- Fonts: Press Start 2P + VT323 (Google Fonts).
- Deploys on Coolify with the `static` build pack (served by `nginx:alpine`).

## Local preview

```sh
python3 -m http.server 8000
```
